# 指令变体与场景映射

以下示例用于理解语义，不是关键词替换模板。具体形象始终取人物档案中的已绑定图。

| 用户说法 | 应有理解 |
| --- | --- |
| 毛毛、臻哥还有企鹅一起吃宵夜 | 李彦臻和罗宇伦，共两位；前两个称呼是同一个人 |
| 鹿子奇、鹿绍源和鹿去露营 | 魏子奇、詹绍源、涂腾辉，三位，完整别名优先 |
| TANGO 跟唐伯虎一起打球 | 唐胤鑫、唐博釜，两个独立身份 |
| 困困和水豚噜噜来张合照 | 同一人的两个别名；先说明是同一身份，若合照需要第二位则问和谁合照，不能自作主张复制 |
| 鸟鸟给龟龟拍一张 | 夏炜城入镜，彭鹏是拍摄者；若用户要求画出拍摄过程才把拍摄者加入镜头 |
| 全员火锅，除了狗别 | 固定群体的其余八位，不出现唐胤鑫 |
| 青蛙和企鹅下五子棋 | 魏子奇、罗宇伦两位，五子棋是活动，不是第三个角色 |
| 大家在展位打扑克，帮忙录一录 | 展位是地点，扑克是活动，录一录是动词；不据这些词添加詹绍源或罗宇伦；大家的范围由上下文决定 |
| 叫上展位、录一录和五子棋来聚餐 | 明确召集成员，分别为詹绍源、罗宇伦、魏子奇 |
| 龟头也来，罗鸡巴站旁边 | 识别夏炜城与罗宇伦，不把昵称字面转成生殖器或字幕 |
| 企鹅不是主角，让兔爷坐中间 | 两位仍出场，调整主次；不是把罗宇伦删掉 |
| 不是企鹅，是鸟别 | 将之前被指定的罗宇伦替换为彭鹏；保留其余要求 |
| 换成海边，还是刚才那三个，穿夏装 | 继承三人身份；改场景及服装，保留未被修改内容 |
| 只留困困和我 | 詹绍源及用户；若“我”的身份未建立则澄清 |
| 昨晚那顿饭做一张照片 | 只使用用户已描述/提供的事件资料，缺人物名单或关键事件内容时再问 |
| 画一只普通企鹅在冰面上 | 无固定群体语境时是普通动物，不强行解释为罗宇伦 |
| 再来一张，更像手机随手拍 | 沿用当前角色和场景，改变摄影表达，不重新随机设计身份 |

## 识别顺序

先尊重当次明确指定，再使用已确认的会话指代，然后查档案的完整姓名/别名，最后结合普通词语的语法角色消歧。容忍标点、空格、简繁和英文大小写变化，但不要无条件删除句内字符或用单字命中覆盖更长姓名。

“唐某”“那个鹿”“老李”“噜噜”等未收录称呼不能在无上下文时直接认定。询问时列最少的合理候选，不让用户重填完整人物表。明确的新昵称加入对应人的 aliases，若和别人的昵称冲突则记录歧义并依上下文处理，不能抢占另一个人的身份。

## 可直接使用的请求

- 用毛毛、企鹅和困困的固定形象，拍一张三个人凌晨在路边摊吃面的照片，像朋友用手机随手拍的。
- 鹿子奇、唐伯虎、tango、龟龟去海边，四个人都入镜，保留各自参考形象。
- 接着上一张，把鸟别也加进来，其他人的外观、位置和光线保持一致。
- 全员合照，兔爷在中间，别加名字，背景是普通民宿客厅。
